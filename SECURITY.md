# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x (`v1`) | :white_check_mark: |
| < 1.2   | :x:                |

Only the latest release (tracked by the `v1` tag) receives security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues.

Instead, use GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/wei18/local-composite-action/security/advisories/new)

You can expect an initial response within a week. Please include a description
of the issue, steps to reproduce, and the affected version or workflow setup.
